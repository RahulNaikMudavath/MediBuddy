# MediBuddy Medicine Search

A React-based medicine search application using the FDA Drug Label API.
The live hosted url:
*https://medibuddy-r5g6.onrender.com*

## Features

- Search medicines by brand name
- Debounced API requests
- Medicine result cards
- Medicine detail page
- Loading, empty and error states
- Request cancellation
- Search result caching
- Direct detail-page access
- Responsive design

## Tech Stack

- React
- JavaScript
- Vite
- React Router
- FDA Drug Label API

## Run Locally

```bash
npm install
npm run dev
